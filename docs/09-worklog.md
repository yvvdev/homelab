## 2026-10-09 (вечер) — подготовка сервера

### Сеть (P-01)
- Выяснено: из-за опечатки `auto vmdr0` мост не поднимался при загрузке; сеть была поднята вручную (адрес `.100` в памяти, `.101` в файле).
- Создана резервная копия `/etc/network/interfaces.bak-2026-10-09`, записан исправленный файл (`vmbr0`, `192.168.1.100/24`), проверка `ifquery -a`, применение `ifreload -a` — без обрыва связи.
- Проверено перезагрузкой: сеть поднимается сама, туннель работает.
- Ложная тревога «туннель не работает»: в браузере была опечатка в имени домена (`NXDOMAIN`); с правильным адресом доступ снаружи подтверждён с телефона.

### Репозитории и обновление (P-02)
- Через веб-интерфейс отключены `pve-enterprise` и `ceph-squid enterprise`, добавлены `pve-no-subscription` и `ceph-squid no-subscription`.
- `apt update` — без ошибок; `apt full-upgrade` с физической консоли, ~270 пакетов.
- Результат: Proxmox VE 9.0.3 → **9.2.21**, ядро 6.14.8-2 → **7.0.14-23**. Перезагрузка, всё поднялось.

### SSH
- Отпечаток ключа сервера сверен вручную (`ssh-keygen -lf` на сервере).
- Публичные ключи `tool-os-wsl` (`ssh-copy-id`) и `tool-os-ssd` (через PowerShell) добавлены в `/root/.ssh/authorized_keys`.
- В WSL создан `~/.ssh/config` с алиасом `pve`.
- Создан `/etc/ssh/sshd_config.d/10-hardening.conf` (только ключи), проверка `sshd -t` / `sshd -T`, `systemctl reload ssh`.
- Проверено: `ssh pve` — вход по ключу; вход по паролю — `Permission denied (publickey)`.

### Защита веб-интерфейса (P-03)
- Cloudflare Zero Trust: создано приложение Access `Proxmox` (Self-hosted, Public DNS), политика `Only me` (почта владельца, One-time PIN), сессия 24 ч, HTTP Only cookie.
- Проверено с телефона через мобильную сеть: разрешённая почта — вход; посторонняя — отказ.
- Proxmox: для `root@pam` добавлены TOTP и коды восстановления.

### VM (P-04)
- Удалены VM 101 `dadada` и 102 `dada` вместе с дисками.
- VM 100 `wVM`: CPU 4×3 → 1×4, RAM 8 → 4 ГБ.

### Туннель
- Добавлен drop-in `cloudflared.service.d/override.conf` (`After=network-online.target`); проверено перезагрузкой — туннель поднимается автоматически.

### Аудит и документация
- Финальный аудит выполнен одним запуском с рабочей станции (`ssh pve 'bash -s' > файл`).
- Уточнено оборудование: плата HUANAN X79, RAM 4 × 4 ГБ DDR3-1600, сетевой адаптер Realtek RTL8111.
- Документация обновлена до v3. Все проблемы P-01…P-04 закрыты.
