# 3. Реестр виртуальных машин и контейнеров

> **Версия:** v1 · **Дата:** 2026-10-08 · **Статус:** шаблон — заполняется при аудите сервера

Реестр ведётся по **всем** VM и LXC, включая удалённые (со статусом «удалена» и датой).

## 3.1. Схема нумерации VMID

| Диапазон | Назначение |
|---|---|
| 100–199 | Служебные машины (инфраструктура) |
| 200–299 | Кластер Kubernetes |
| 300–399 | Эксперименты и тесты |
| 9000–9099 | Шаблоны (templates) |

## 3.2. Сводный реестр

| VMID | Имя | Тип | ОС | vCPU | RAM | Диск | IP | Назначение | Статус |
|---|---|---|---|---|---|---|---|---|---|
| ⏳ | | VM / LXC | | | | | | | |

**Сводка ресурсов** (обновлять при изменениях):

| Ресурс | Всего на хосте | Выделено | Свободно |
|---|---|---|---|
| RAM | 16 ГБ | ⏳ | ⏳ |
| Диск | 2 ТБ | ⏳ | ⏳ |

## 3.3. Карточка машины (шаблон)

Для каждой машины копируется блок ниже.

```markdown
### VMID — имя

| Параметр | Значение |
|---|---|
| Тип | VM / LXC |
| ОС | |
| Ресурсы | vCPU / RAM / диск |
| Сеть | мост, IP, шлюз |
| Назначение | |
| Создана | дата, способ (вручную / Terraform) |
| Установленное ПО | |
| Доступ | пользователь, способ входа |
| Бэкап | да/нет, расписание |
| Зависимости | от каких машин зависит |
| Примечания | |
```
