# 3. Реестр виртуальных машин и контейнеров

> **Версия:** v3 · **Дата:** 2026-10-09 · **Статус:** действующий

Реестр ведётся по **всем** VM и LXC, включая удалённые (со статусом «удалена» и датой).

## 3.1. Схема нумерации VMID (для новых машин)

| Диапазон | Назначение |
|---|---|
| 100–199 | Служебные и тестовые машины |
| 200–299 | Кластер Kubernetes |
| 300–399 | Эксперименты и тесты |
| 9000–9099 | Шаблоны (templates) |

## 3.3. Карточки машин

### 100 — wVM

| Параметр | Значение |
|---|---|
| Тип | VM (QEMU/KVM), машина `q35`, `cpu: host` |
| ОС | Windows 10 22H2 (RU) |
| Ресурсы | 1 сокет × 4 ядра, 4 ГБ RAM, диск 200 ГБ (`local-lvm:vm-100-disk-0`, VirtIO SCSI, iothread) |
| Сеть | `vmbr0`, адаптер VirtIO, firewall Proxmox включён; IP ⏳ |
| Подключённые ISO | Win10_22H2_Russian_x64v1.iso, virtio-win-0.1.285.iso |
| Назначение | Тестирование Windows-ПО |
| Создана | До начала проекта, вручную |
| Изменена | 2026-10-09: CPU 4×3 → 1×4, RAM 8 ГБ → 4 ГБ |
| Бэкап | Нет |

### 101 — dadada (удалена)

Windows 10, 3×4 vCPU, 8 ГБ, диск 174 ГБ (IDE), сеть e1000. Удалена 2026-10-09 вместе с диском (`qm destroy 101 --purge 1 --destroy-unreferenced-disks 1`) как неиспользуемая. См. [ADR-010](08-decisions.md).

### 102 — dada (удалена)

Windows 10, 3×4 vCPU, 8 ГБ, диск 32 ГБ (IDE), сеть e1000. Удалена 2026-10-09 вместе с диском. См. [ADR-010](08-decisions.md).
