# 4. Сеть

> **Версия:** v1 · **Дата:** 2026-10-08 · **Статус:** частично заполнен

## 4.1. Общие сведения

| Параметр | Значение |
|---|---|
| Подключение к интернету | Через домашний роутер |
| Внешний IP | **Серый** (за NAT провайдера), входящие подключения из интернета напрямую невозможны |
| Локальная подсеть | ⏳ уточнить (например, `192.168.1.0/24`) |
| Шлюз | ⏳ |
| DNS | ⏳ |
| Сетевой мост Proxmox | ⏳ (обычно `vmbr0`) |

## 4.2. План адресации

| IP | Устройство / машина | Тип адреса | Примечание |
|---|---|---|---|
| ⏳ | Роутер | статический | шлюз |
| ⏳ | Сервер Proxmox | статический | |
| ⏳ | Рабочая станция | DHCP | |
| ⏳ | VM … | статический | см. [03](03-virtual-machines.md) |

## 4.3. Удалённый доступ — Cloudflare Tunnel

| Параметр | Значение |
|---|---|
| Домен | ⏳ (имя домена — внести; не секрет) |
| Где работает `cloudflared` | Непосредственно на хосте Proxmox |
| Опубликованные сервисы | Веб-интерфейс Proxmox (hostname ⏳) |
| Защита Cloudflare Access | ⏳ проверить (планируется включить) |
| Токен туннеля | **Секрет** — хранится только на сервере, в документацию не вносится |

## 4.4. Способы доступа к серверу

| Ситуация | Способ |
|---|---|
| Рабочая станция в домашней сети | Напрямую по локальному IP |
| Рабочая станция вне дома | Через домен (Cloudflare Tunnel) |
| Резервный канал | ⏳ планируется (Tailscale / WireGuard) |

## 4.5. Используемые порты

| Порт | Протокол | Сервис | Доступен из |
|---|---|---|---|
| 22 | TCP | SSH | Локальная сеть |
| 8006 | TCP | Веб-интерфейс Proxmox | Локальная сеть, через туннель |
