# 1. Оборудование

> **Версия:** v1 · **Дата:** 2026-10-08 · **Статус:** действующий

## 1.1. Домашний сервер

| Параметр | Значение |
|---|---|
| Назначение | Гипервизор Proxmox VE, полигон для VM и Kubernetes |
| Имя хоста | ⏳ уточнить при аудите |
| Процессор | Intel Xeon E5-1660 v2 (6 ядер / 12 потоков, Ivy Bridge-EP) |
| Оперативная память | 16 ГБ DDR3 (конфигурация модулей ⏳ уточнить) |
| Накопители | 1 × HDD 2 ТБ (модель ⏳ уточнить) |
| Видеокарта | NVIDIA GeForce GTX 550 Ti |
| Материнская плата | ⏳ уточнить |
| Сетевой адаптер | ⏳ уточнить |
| Расположение | Дома, подключён к домашнему роутеру |

**Ограничения и риски:**
- 16 ГБ RAM — основной лимит при развёртывании кластера и мониторинга.
- Единственный HDD: низкая производительность при параллельной нагрузке и **отсутствие отказоустойчивости** — выход диска означает потерю всех данных (см. [07 — Бэкапы](07-backups.md)).
- Видеокарта для вычислительных задач не используется.

**Возможная модернизация** (для справки): SSD под систему и диски VM, увеличение RAM.
