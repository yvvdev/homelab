## 2.6. Команды для аудита

Выполняются в Shell хоста (веб-интерфейс → нода → Shell):

```bash
pveversion
uname -r
free -h
lsblk
pvesm status
qm list
pct list
ip -br a
cat /etc/network/interfaces
systemctl status cloudflared --no-pager
```

> ⚠️ В выводе `systemctl status cloudflared` может быть токен туннеля — **не копировать в документацию**.
