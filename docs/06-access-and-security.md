# 6. Доступ и безопасность

> **Версия:** v1 · **Дата:** 2026-10-08 · **Статус:** действующий

## 6.1. Политика секретов

1. Пароли, токены, приватные ключи, токен Cloudflare Tunnel, внешний IP **не вносятся** в документацию и в Git.
2. В документации указывается только **местоположение** секрета и его назначение.
3. Файлы с секретами добавляются в `.gitignore`.
4. Если секрет попал в Git — он считается скомпрометированным и **перевыпускается** (удаление из истории недостаточно).
