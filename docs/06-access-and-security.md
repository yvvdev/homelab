# 6. Доступ и безопасность

> **Версия:** v4 · **Дата:** 2026-10-13 · **Статус:** действующий

## 6.1. Политика секретов

1. Пароли, токены, приватные ключи, учётные данные Cloudflare Tunnel, коды восстановления, внешний IP **не вносятся** в документацию и в Git.
2. В документации указывается только **местоположение** секрета и его назначение.
3. Файлы с секретами добавляются в `.gitignore`.
4. Если секрет попал в Git — он считается скомпрометированным и **перевыпускается** (удаление из истории недостаточно).

## 6.3. Хранение секретов

| Что | Где хранится |
|---|---|
| Пароли учётных записей, passphrase SSH-ключей, пароль `root` Proxmox | KeePassXC, база `homelab.kdbx` |
| Коды восстановления (Proxmox, GitHub, Cloudflare) | KeePassXC, заметки к соответствующим записям |
| TOTP-коды (второй фактор) | Приложение-аутентификатор на телефоне — **не** в KeePassXC (разделение факторов) |
| Учётные данные Cloudflare Tunnel | Только на сервере, `/root/.cloudflared/` |

База KeePassXC: рабочая копия на рабочей станции, резервная копия — на отдельном носителе. В репозиторий не помещается. Мастер-пароль нигде не записывается.

## 6.4. Реестр SSH-ключей

| Название | Тип | Где хранится приватный ключ | Passphrase | Где установлен публичный | Создан |
|---|---|---|---|---|---|
| `tool-os-ssd` | ed25519 | Windows: `C:\Users\Yarik\.ssh\id_ed25519` | Да | GitHub; сервер `proxmox` (`root`) | 2026-10-08 |
| `tool-os-wsl` | ed25519 | WSL: `/home/yarik/.ssh/id_ed25519` | Да | GitHub; сервер `proxmox` (`root`) | 2026-10-08 |

Содержимое `/root/.ssh/authorized_keys` на сервере (2026-10-09):

| Ключ | Подпись | Назначение |
|---|---|---|
| ssh-rsa | `root@proxmox` | Собственный ключ узла Proxmox (создан при установке, используется внутренними механизмами) |
| ssh-ed25519 | почта владельца | `tool-os-ssd` или `tool-os-wsl` |
| ssh-ed25519 | почта владельца | `tool-os-ssd` или `tool-os-wsl` |

> У обоих ключей рабочей станции одинаковая подпись (почта) — на сервере их не различить. ⏳ При следующей ротации ключей задавать разные комментарии (`-C "yarik@tool-os-wsl"`).

При отзыве ключа: удалить публичную часть со всех систем из столбца «Где установлен», сделать запись в журнале работ.

SSH-клиент WSL, `~/.ssh/config`:

```
Host pve
    HostName 192.168.1.100
    User root
    IdentityFile ~/.ssh/id_ed25519
```

## 6.6. Модель защиты доступа к серверу

| Канал | Уровни защиты |
|---|---|
| Веб-интерфейс через интернет | 1) Cloudflare Access — код на почту, только разрешённый адрес; 2) пароль `root`; 3) TOTP |
| Веб-интерфейс из локальной сети | 1) пароль `root`; 2) TOTP |
| SSH | Только ключ ed25519 (с passphrase); вход по паролю запрещён; доступен только из локальной сети |
| Физическая консоль | Пароль `root` (TOTP не действует) |

Резервный доступ при потере телефона с TOTP: коды восстановления (Recovery Keys) — в KeePassXC; SSH по ключу и консоль продолжают работать.
