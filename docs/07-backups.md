# 7. Резервное копирование

> **Версия:** v3 · **Дата:** 2026-10-09 · **Статус:** план

## 7.1. Принципы

- **Правило 3-2-1:** 3 копии данных, на 2 разных носителях, 1 — вне основного места.
- **Снапшот — не бэкап:** он хранится на том же диске и погибает вместе с ним.
- **Непроверенный бэкап — не бэкап:** восстановление проверяется регулярно.
- Код и конфигурации хранятся в GitHub — это тоже копия; всё, что можно, описывается кодом.

## 7.2. Объекты резервного копирования

| Объект | Метод | Куда | Периодичность | Статус |
|---|---|---|---|---|
| Рабочая станция (внешний SSD) | Образ диска | ⏳ | После завершения настройки, далее по изменениям | ⬜ этап 8 |
| Конфигурация рабочей станции | Скрипты и dotfiles в Git | GitHub | При изменениях | ⬜ этап 6 |
| Конфигурация хоста Proxmox | ⏳ архив `/etc/pve`, `/etc/network`, `/etc/ssh/sshd_config.d`, `/etc/cloudflared`, `/etc/systemd/system/cloudflared.service*` | ⏳ (учесть: в `/etc/cloudflared` и `/root/.cloudflared` — секреты) | ⏳ | ⬜ |
| Коды восстановления TOTP Proxmox | Вне сервера | Менеджер паролей / распечатка | Однократно | ⏳ подтвердить |
| Виртуальные машины | `vzdump` / Proxmox Backup Server | ⏳ (внешний носитель) | ⏳ | ⬜ |
| Документация | Git | GitHub | При изменениях | ⬜ этап 5 |
