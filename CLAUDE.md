## Правила документации (обязательно)

Полная документация проекта — в `docs/` (описание в `README.md`). Ведётся постоянно, в официальном стиле.

1. После любой работы обновлять соответствующие документы: оборудование → `01`, ПО сервера → `02`, VM/LXC → `03`, сеть → `04`, рабочая станция → `05`, доступы и ключи → `06`, бэкапы → `07`, решения → `08` (ADR), действия → `09` (журнал работ, новые записи сверху).
2. **Версионирование:** единая версия на всю документацию — `v1`, `v2`, `v3`… Каждое обновление документации = новая версия: запись в `CHANGELOG.md` (сверху), обновить «Версия/Дата» в шапке изменённых документов, в `README.md` и в этом файле; коммит и тег `git tag vN`.
3. Секреты (пароли, токены, приватные ключи, токен туннеля, внешний IP) — **никогда** в документацию и Git. Только место хранения.
4. Неизвестное помечать `⏳ уточнить`.
5. В конце проекта — финальные схемы в `docs/diagrams/` (Mermaid).

## Цель проекта

Освоить навыки DevOps на домашнем сервере и собрать портфолио на GitHub:
виртуализация → IaC (Terraform/OpenTofu + Ansible) → Docker → Kubernetes → мониторинг и логи → своё приложение с CI/CD и GitOps.

## Краткая сводка инфраструктуры

Подробно — в `docs/01`–`docs/07`.

- **Сервер `proxmox`:** HUANAN X79, Xeon E5-1660 v2, 16 GB DDR3 (4×4), 1 × HDD Seagate ST2000DM001 2 TB (SMART OK, ~19,5 тыс. ч), Realtek RTL8111, GTX 550 Ti. **Proxmox VE 9.2.21**, ядро 7.0.14 (Debian 13), репозитории no-subscription. LVM-thin (`local` 96 GB, `local-lvm` 1,7 TB). Сеть 192.168.1.0/24, хост **192.168.1.100** на мосту `vmbr0`, шлюз .1. Физический доступ к серверу есть.
- **Доступ:** SSH только по ключам (`ssh pve` из WSL; ключи Windows и WSL в `authorized_keys`). Веб-интерфейс: локально — пароль + TOTP; снаружи — Cloudflare Access (код на почту) → туннель `proxmox-tunnel` → пароль + TOTP. `cloudflared` на хосте, стартует после `network-online.target`.
- **VM:** только 100 `wVM` (Windows 10, тест, 1×4 vCPU, 4 GB, выключена).
- **Рабочая станция:** ноутбук i5-13500H, 24 GB RAM. Windows 11 Pro (официальный ISO) на внешнем USB SSD, учётка `Yarik`. WSL2: Ubuntu 24.04, пользователь `yarik`, проекты в `~/projects`. VS Code связан с WSL.

## Правила работы с сервером

- Перед правкой конфига — резервная копия; свои настройки — в drop-in файлах (`*.d/`), а не в основных конфигах.
- Правка сети и обновления — с физической консоли или по SSH, не через Shell веб-интерфейса.
- Обновление Proxmox: `apt update && apt full-upgrade`, затем перезагрузка при новом ядре.
- Новые VM: `sockets: 1`, VirtIO, минимально нужная RAM; нумерация VMID — в `docs/03`.
