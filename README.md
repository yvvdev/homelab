## Правила ведения

1. **Версия** — единая для всей документации: `v1`, `v2`, `v3`… Любое изменение документации повышает версию.
2. Каждая версия: запись в [CHANGELOG.md](CHANGELOG.md), обновление поля «Версия» в шапке изменённых документов и в этом файле, коммит и Git-тег (`git tag v2`).
3. Каждое действие на инфраструктуре фиксируется в [журнале работ](docs/09-worklog.md).
4. Каждое значимое решение («почему так, а не иначе») — в [журнале решений](docs/08-decisions.md).
5. **Секреты (пароли, токены, приватные ключи, внешний IP) в документацию не вносятся.** Указывается только, *где* секрет хранится.
6. Неизвестные данные помечаются `⏳ уточнить`, а не пропускаются.
